# TypeBlitz ⚡

A Python-based typing speed game built using Tkinter. Test your typing speed, accuracy, and progress in a timed challenge.

## Features

- **60-second typing challenge** to test your speed.
- **Live WPM tracking** to measure words per minute.
- **Accuracy calculation** to track typing accuracy.
- **Progress bar** showing your progress through the passage.
- **Results screen** displaying your final statistics.
- **Play Again and Home options** for replaying the game.

## Technologies Used

- Python 3
- Tkinter for the graphical user interface
- Git and GitHub for version control and project hosting

## Requirements

- Python 3 installed on your computer.
- Tkinter, which is included with most standard Python installations.

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   ```bash
   python TypeBlitz.py
   ```

4. Start typing and try to achieve your best speed and accuracy!

## How WPM Is Measured

WPM stands for **Words Per Minute**. TypeBlitz uses the number of words typed and the time taken to calculate typing speed.

## Project Purpose

TypeBlitz is a mini-project created to practise Python programming, GUI development, event handling, and basic software version control.
